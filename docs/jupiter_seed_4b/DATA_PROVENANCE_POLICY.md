# Jupiter Seed 4B: Data Provenance Policy

This policy governs the collection, generation, and storage of all training and evaluation data for Jupiter Seed 4B. Strict adherence to this policy is mandatory to ensure legal compliance, model quality, and enterprise readiness.

## Mandatory Record Preservation

Every single training record must preserve the following metadata:

| Field | Description |
| :--- | :--- |
| **Record ID** | A unique, immutable identifier for the specific data instance. |
| **Source type** | The origin category of the data (e.g., synthetic generation, human-curated, public dataset). |
| **Source licence** | The exact legal license governing the original source material. |
| **Source URL/ID** | The specific URL or internal identifier linking back to the exact source. |
| **Teacher model** | The name of the model used for generation or scoring (if applicable). |
| **Exact teacher version** | The specific version tag or commit hash of the teacher model used. |
| **Generation configuration** | The exact parameters used during generation (e.g., temperature, top-p, max tokens). |
| **Original prompt** | The exact text of the prompt provided to the teacher model or human annotator. |
| **Teacher response** | The exact, unedited output generated by the teacher model. |
| **Filtering decision** | The outcome of the quality filtering process (e.g., Accepted, Rejected, Modified). |
| **Quality score** | The numerical or categorical score assigned during evaluation. |
| **Language** | The primary language of the text (e.g., Arabic, English). |
| **Domain** | The specific enterprise domain the text relates to (e.g., GCC banking, telecom operations). |
| **Safety classification** | The result of safety and toxicity screening. |
| **Reviewer status** | Indicates whether the record has been reviewed by a human (e.g., Pending, Human-Reviewed). |
| **Date generated** | The timestamp when the record was created. |
| **Redistribution permitted** | A boolean flag indicating if the data can be legally shared outside AgenThink. |

## Prohibited Data

The inclusion of the following types of data in the training corpus is strictly prohibited:

1. **Customer-confidential information:** Any data that belongs to a customer and is not explicitly cleared for model training.
2. **Personal data without an approved legal basis:** Any personally identifiable information (PII) that violates privacy regulations like GDPR or local GCC data protection laws.
3. **Copyrighted books without rights:** Any published material where explicit permission for training has not been secured.
4. **Paywalled material without rights:** Any content scraped or accessed from behind a paywall without proper licensing.
5. **Scraped private communications:** Any emails, chat logs, or private messages.
6. **Unlicensed commercial databases:** Any structured data acquired from commercial vendors without a license permitting model training.
7. **Hidden chain-of-thought extraction:** Attempting to extract the internal reasoning steps of a teacher model if explicitly forbidden by its license. (Note: Teachers may provide concise, user-facing explanations or verifiable solution steps, provided it does not violate the license).
8. **Outputs from APIs whose terms prohibit model training:** Any data generated by commercial APIs (e.g., OpenAI, Anthropic) if their Terms of Service forbid using the output to train competing models.
9. **Material with unclear provenance:** Any data where the original source or licensing status cannot be definitively proven.
