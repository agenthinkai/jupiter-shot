## Assessment Criteria for Candidates

Each candidate must be evaluated against the following criteria before final approval:
- Exact licence
- Commercial-use permission
- Modification permission
- Distillation permission
- Synthetic-output training permission
- Redistribution requirements
- Attribution requirements
- Arabic capability
- English capability
- Reasoning quality
- Enterprise-document performance
- Self-hosting requirements
- GPU memory requirements
- Inference cost
- Output-data ownership
- Provenance risk
- Export and jurisdiction considerations
- Compatibility with PyTorch
- Compatibility with Hugging Face
- Compatibility with vLLM
- Compatibility with llama.cpp and GGUF
